# OBS Jukebox

Separate GD/Song output for OBS. Also keeps sound effects. No driver/audio cable installation.

<img width="1965" height="1344" alt="image" src="https://github.com/user-attachments/assets/55ee1a25-3af0-42bc-b442-13518b669613" />


## Installation

1. Go to **Releases** on the right
2. Download the executable for your platform (.exe for Windows, for example)
3. Run it, accept defaults.
4. It will ask you to close OBS and GD if they are running.
<img width="717" height="636" alt="image" src="https://github.com/user-attachments/assets/caaf8b6f-a84d-44ff-be6e-cb0466733efd" />

Done! Change OBS/Game volume in pause menu. Other options in geode mod menu.

On Windows, the installer creates a source in OBS. On macOS, add **GD Sounds** once after installation.

<img width="111" height="233" alt="image" src="https://github.com/user-attachments/assets/3af2ad0d-5e2f-489b-814f-e33b7ae55eb9" />

## Usage

In Jukebox, check 'Game' for your in-game audio (not heard in OBS' output) and 'OBS' for the OBS output (not heard in game)
Toggle between Game/OBS volume control in pause menu.
<img width="1848" height="285" alt="image" src="https://github.com/user-attachments/assets/11024e80-051b-41e3-87dd-5e31e00a6cb8" />

## Compatibility

Windows x64 and macOS 13+ (Apple Silicon) are (somewhat) supported. Linux support through Proton is experimental.

There is code generated by LLMs in this repository. I understand if you do not want to use it for that reason.

It (seemingly) works fine, though no code, written by LLMs or humans, is bug and issue free, but I suspect that LLM generated code is scrutinized to a higher degree than that of handwritten code.

Regardless, do keep this in mind when using it, though I did *actually* try not to make this mod slop. If you believe it is, that's okay.
