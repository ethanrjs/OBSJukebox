# OBS Jukebox

Separate GD/Song output for OBS. Also keeps sound effects. No driver/audio cable installation.

## Installation

1. Go to **Releases** on the right
2. Download the executable for your platform (.exe for Windows, for example)
3. Run it, accept defaults.
4. It will ask you to close OBS and GD if they are running.

Done! Change OBS/Game volume in pause menu. Other options in geode mod menu.

## Usage

In Jukebox, check 'Game' for your in-game audio (not heard in OBS' output) and 'OBS' for the OBS output (not heard in game)

## Compatibility

Windows, macOS 13+ on Apple Silicon, and x86_64 Linux.

On macOS, extract the ZIP and open **OBS Jukebox Setup**. The installer is not notarized, so macOS may require approval in **System Settings > Privacy & Security**. Add **GD Sounds** in OBS once after installation.

On Linux, Geometry Dash runs through Proton with Geode installed. Extract the archive and run `bash Install.sh`. Use `bash Install.sh --flatpak` for Flatpak OBS. Install Jukebox through Geode if needed, then add **GD Sounds** in OBS once.
