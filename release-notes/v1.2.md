# OBS Jukebox v1.2
A bunch of bugs and issues fixed + smoother OBS audio + better installer.

## Highlights

- Play does not get stuck anymore. If your OBS song isn't downloaded, or you're offline, the level starts right away and OBS plays the normal game song instead.
- Smoother OBS audio interactions with song triggers and changes
- Far less work in the background / performance improvemnts
- No jukebox update crash
- Uninstaller improvements

## Fixes and improvements

### **Game**
- The OBS checkbox no longer shows up on "Download nongs" rows.
- Fixed flicker in the Jukebox list when changing the game song.
- The offset setting now shows which level it's for.
- Song and level names with special characters show up correctly in OBS.
- Very long file paths now show a message.

### **OBS**
- Song trigger improvements.
- Multiple GD instances no longer contest OBS.
- SFX on surround sound fixed
- Using source in multiple locations no longer causes double audio

### **Installer**
- Adding GD Sounds to your scenes is now optional.
- The installer only asks for admin rights for the step that needs them, and won't reopen GD or OBS as admin.
- Works when OBS is minimized to the tray.
- Mac: the plugin is less likely to get blocked by macOS security.
- Linux: checks that you have the right Jukebox version.
- Shows a message when it's done.

Plus a lot of behind-the-scenes cleanup.

**Requires:** Geode 5.10.1 or newer, and Jukebox 3.8.0
